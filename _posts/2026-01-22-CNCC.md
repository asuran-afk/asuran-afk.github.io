#### Vulnerability Analysis
In order to trigger the `show_flag` function, we must pass the check `current_balance == 1000000`. `current_balance` set to 100 before the check. The key vulnerability is that our `amount_to_withdraw` is only checked if we input 0, it did not check if our input is negative, which means we can input negative value to make our `current_balance == 1000000`. `100 - 1000000 = -999900`, so the solution is `-999900`.
